Why Re-Calibrate in May 2026 If Cal Files Already Existed?

Context: Box already had SN8030 factory cal (Hyper-bb_SN8030, Dec 2025). Jul–Nov 2025 Proc files used that state. In May 2026, Harrison ran a new Calibration Tank calibration anyway.

Why

  1. Operational check — manual says contact Sequoia if tank-cal values (especially mu factor) are out of range.
  2. Not a missing-file problem — old cal files were valid for factory/shipment state; tank cal tests current lab condition of the instrument.
  3. Problem found — mu factor far below expected; Sequoia reviewed pmt/cal/dark .hbb_raw files.

Diagnosis (Sequoia)

  • Instrument electronics OK; calibration tank OK.
  • Plaque signal much lower than factory cal → likely dirty window / plaque / water, especially tape residue from taping windows during dark scans.

Action & result

  • Harrison cleaned window/plaque/water → re-ran tank calibration (May 27, 2026) → all values within expected range. Tape residue = leading cause.
  • Existing 2025 Proc_hbb files unchanged — they reflect cal at export time. Only new exports after May 2026 re-cal pick up the updated instrument cal.

Bottom Line

  • Two instruments, two pipelines: SN8002 → hbb_*.txt + .mat → Beta_u; SN8030 → Proc_hbb_*.txt → val1.
  • Two software eras: SN8030 = Sequoia Hyper-BB SW v2.1 (FW 1.76); SN8002 = legacy txt export, version unknown, cal applied in PhytoBloom.
  • May 2026 re-cal = verification of current SN8030 condition, not replacement of missing files; cleaning fixed mu factor; 2025 data still valid as exported.

beta to bb conversion (applied in this report)

Hyper-BB measures the volume scattering function at a single angle (β(135°), units m-1 sr-1), not the angle-integrated backscattering coefficient bb. The full definition is an integral of β(θ) over the backward hemisphere; for single-angle sensors this is approximated with a chi factor (Boss & Pegau 2001):

bb ≈ 2π · χ(135°) · β(135°),    with χ = 1.164

All spectra in tab (2) and in F02_hbb_spectra.csv use this conversion so plotted / exported values are bb (m-1).
