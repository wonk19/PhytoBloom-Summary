1. Overview

Hyper-a determines the spectral absorption coefficient \(a(\lambda)\) using an integrating cavity. The retrieval is not a simple gain/offset correction or a direct Beer–Lambert calculation. Instead, the instrument response is represented by a PSICAM-type integrating-cavity model that explicitly accounts for multiple reflections and effective photon path lengths inside the sphere.

\(r_0\)

\(\rho(\lambda)\)

2. Raw Spectral Correction

Raw signal- and reference-detector counts are first corrected using the temporally nearest dark measurement.

\[ S'(\lambda)=S_{\mathrm{raw}}(\lambda)-S_{\mathrm{dark}}(\lambda) \] \[ R'(\lambda)=R_{\mathrm{raw}}(\lambda)-R_{\mathrm{dark}}(\lambda) \]

The corrected signal and reference spectra are then interpolated onto the common wavelength grid defined by cal.wl. The normalized Hyper-a signal is

\[ \boxed{ H(\lambda)=\frac{S'(\lambda)}{R'(\lambda)} } \]
MATLAB implementation — Hypera_lib.m, function CorrectSpectrum()
sig_darkCorr = lightData.sigPix(n,:) ...
             - medianDarkData.median_sigPix(closestIndex,:);

ref_darkCorr = lightData.refPix(n,:) ...
             - medianDarkData.median_refPix(closestIndex,:);

AllDarkRefCorrected(n,:) = ...
    interp1(config.sigWls(:)', sig_darkCorr, cal.wl(:)') ./ ...
    interp1(config.refWls(:)', ref_darkCorr, cal.wl(:)');

Thus, CorrectSpectrum() performs: dark subtraction → wavelength interpolation → signal/reference normalization.

3. Integrating-Cavity Optical Model

The cavity model uses the probability function \(P_s\), implemented in Hypera_lib.Ps():

\[ \boxed{ P_s(a,r)= \frac{1-e^{-2ar}(2ar+1)} {2a^2r^2} } \]
MATLAB implementation — Hypera_lib.m, function Ps()
Ps_x = (1 - exp(-2 .* a .* r) .* (2 .* a .* r + 1)) ...
     ./ (2 .* a.^2 .* r.^2);

For two absorption states A and B, the measured ratio is defined as

\[ T_{AB}(\lambda)=\frac{H_A(\lambda)}{H_B(\lambda)} \]

This ratio is related to \(a_A\), \(a_B\), \(r\), \(r_0\), and sphere reflectivity \(\rho(\lambda)\).

4. Factory Calibration: Determination of Sphere Reflectivity

Factory calibration determines the effective spectral reflectivity of the integrating sphere, \(\rho(\lambda)\), using two states whose absorption coefficients are known.

Given known \(a_A(\lambda)\) and \(a_B(\lambda)\), and measured \(T_{AB}=H_A/H_B\), sphere reflectivity is obtained by inversion:

\[ \boxed{ \rho(\lambda)= \frac{ T_{AB}e^{-a_Br_0}P_s(a_B,r) - e^{-a_Ar_0}P_s(a_A,r) }{ T_{AB}e^{-a_Br_0}P_s(a_A,r)P_s(a_B,r) - e^{-a_Ar_0}P_s(a_B,r)P_s(a_A,r) } } \]
Known \(a_A,a_B\) + measured \(H_A,H_B\) → \(T_{AB}\) → \(\rho(\lambda)\)
MATLAB implementation — Hypera_lib.m, function ComputeRho()
T_AB = A_hypera ./ B_hypera;
T_AB = smoothdata(T_AB, 2, 'sgolay', 15);

rho = (T_AB .* exp(-a_B .* r_0) .* Hypera_lib.Ps(a_B,r) ...
     - exp(-a_A .* r_0) .* Hypera_lib.Ps(a_A,r)) ...
    ./ ...
     (T_AB .* exp(-a_B .* r_0) .* Hypera_lib.Ps(a_A,r) .* Hypera_lib.Ps(a_B,r) ...
     - exp(-a_A .* r_0) .* Hypera_lib.Ps(a_B,r) .* Hypera_lib.Ps(a_A,r));

5. ND-Spot Field Calibration

During field calibration, a Fluorilon white plug and an ND black spot are measured with pure water in the sphere. The purpose is to calculate a new sphere reflectivity representing the current optical state of the instrument.

5.1 White-plug measurement

With pure water and the Fluorilon white plug installed, the absorption state is represented by the modeled pure-water absorption:

\[ \boxed{ a_W(\lambda)=a_{\mathrm{water}}(\lambda,T_W,S=0) } \]
MATLAB implementation — Hypera_RhoFromNDSpot.m
purewater_DarkRefCorrected = ...
    Hypera_lib.CorrectSpectrum(cal, pureWater.dataTable, pureWater.config);

PureWater_aW_modeled = ...
    Hypera_lib.Get_IOCCG_aW(cal.wl, T_pureWater, 0)';

5.2 ND black-spot measurement

With pure water still present, the white plug is replaced by the ND black spot. The spot contributes a known equivalent absorption spectrum stored as cal.spotAbsorp.

\[ \boxed{ a_B(\lambda)= a_{\mathrm{water}}(\lambda,T_B)+a_{\mathrm{spot}}(\lambda) } \]
MATLAB implementation — Hypera_RhoFromNDSpot.m
spot_DarkRefCorrected = ...
    Hypera_lib.CorrectSpectrum(cal, spot.dataTable, spot.config);

Cal_spot_aW_modeled = ...
    Hypera_lib.Get_IOCCG_aW(cal.wl, T_spot, 0)';

Cal_spot_a_total = cal.spotAbsorp + Cal_spot_aW_modeled;

6. Calculation of Field Reflectivity from White/Black Measurements

Let \(H_W(\lambda)\) be the corrected white-plug measurement and \(H_B(\lambda)\) the corrected ND-spot measurement. Their ratio is

\[ \boxed{ T_{BW}(\lambda)=\frac{H_B(\lambda)}{H_W(\lambda)} } \]

In the call to Hypera_lib.ComputeRho(), the ND-spot state is passed as state A and the white-plug pure-water state as state B:

\[ a_A=a_{\mathrm{water}}+a_{\mathrm{spot}}, \qquad a_B=a_{\mathrm{water}} \]
\[ \boxed{ \left[ a_{\mathrm{water}}, a_{\mathrm{spot}}, \frac{H_B}{H_W}, r, r_0 \right] \longrightarrow \rho_{\mathrm{field}}(\lambda) } \]
MATLAB implementation — Hypera_RhoFromNDSpot.m
rho = Hypera_lib.ComputeRho( ...
    cal.r, ...
    cal.r_0, ...
    Cal_spot_a_total, ...
    PureWater_aW_modeled, ...
    median(spot_DarkRefCorrected.NoFilter, 1), ...
    median(purewater_DarkRefCorrected.NoFilter, 1));

rho = smoothdata(rho, "sgolay", 30);
Interpretation: the White/Black procedure does not merely generate a diagnostic drift index. It directly produces a new wavelength-dependent sphere reflectivity \(\rho_{\mathrm{field}}(\lambda)\).

7. Relationship Between Factory and Field Calibration

\[ \boxed{ \text{Factory calibration} \longrightarrow r,\;r_0,\;\rho_{\mathrm{factory}}(\lambda),\; a_{\mathrm{spot}}(\lambda) } \]

The calibrated ND spot then serves as a transfer standard during field operation:

\[ \boxed{ a_{\mathrm{spot}}(\lambda) + \text{White/Black measurements} \longrightarrow \rho_{\mathrm{field}}(\lambda) } \]

Thus, cal.spotAbsorp represents a previously characterized property of the ND spot, whereas \(\rho(\lambda)\) is the intermediate calibration parameter describing the current cavity response.

Code-level distinction: Hypera_RhoFromNDSpot() returns a new variable rho. It does not internally overwrite cal.rho. Therefore, the calling workflow must explicitly use the newly calculated reflectivity for subsequent sample retrieval, for example by assigning it to cal.rho or by constructing an updated calibration structure.

8. Sample Absorption Retrieval

After calibration, pure water is used as the optical reference and an unknown sample is measured. After dark/reference correction, the observed sample-to-water ratio is

\[ \boxed{ T_{\mathrm{obs}}(\lambda)= \frac{ H_{\mathrm{sample}}(\lambda) }{ \operatorname{median}[H_{\mathrm{water}}(\lambda)] } } \]
MATLAB implementation — Hypera_lib.m, function ComputeAbsorption()
r   = cal.r;
r_0 = cal.r_0;
rho = cal.rho;

T_AB = hypera_sample ./ median(hypera_pureWater, 1);
T_AB = smoothdata(T_AB, 2, 'sgolay', 15);

9. Forward Model and Nonlinear Inversion

For an unknown sample absorption \(a(\lambda)\), with pure-water absorption \(a_W(\lambda)\), the model predicts the Hyper-a signal ratio as

\[ \boxed{ \hat{T}(a,\lambda)= e^{-r_0[a(\lambda)-a_W(\lambda)]} \, \frac{ 1-\rho(\lambda)P_s(a_W,r) }{ 1-\rho(\lambda)P_s(a,r) } \, \frac{ P_s(a,r) }{ P_s(a_W,r) } } \]
MATLAB forward model — Hypera_lib.m, function ComputeAbsorption()
T_AB_guess = @(a_guess) ...
    exp(-r_0 .* (a_guess - aW_ref(i_wl))) ...
    .* ((1 - rho(i_wl) .* Hypera_lib.Ps(aW_ref(i_wl),r)) ...
    ./  (1 - rho(i_wl) .* Hypera_lib.Ps(a_guess,r)) ...
    .*  Hypera_lib.Ps(a_guess,r) ...
    ./  Hypera_lib.Ps(aW_ref(i_wl),r));

The retrieved absorption coefficient is the value of \(a\) that minimizes the relative mismatch between model prediction and observation:

\[ E(a)= \frac{ \left|\hat T(a,\lambda)-T_{\mathrm{obs}}(\lambda)\right| }{ T_{\mathrm{obs}}(\lambda) } \]
\[ \boxed{ a_{\mathrm{Hyper\!-\!a}}(\lambda) = \underset{a}{\operatorname{argmin}} \; \frac{ \left|\hat T(a,\lambda)-T_{\mathrm{obs}}(\lambda)\right| }{ T_{\mathrm{obs}}(\lambda) } } \]
MATLAB inversion — Hypera_lib.m, function ComputeAbsorption()
ToMinimize = @(a_guess) ...
    abs(T_AB_guess(a_guess) - T_AB(i_meas,i_wl)) ...
    ./ T_AB(i_meas,i_wl);

a_tot_hypera(i_meas,i_wl) = ...
    fminsearch(ToMinimize, aW_ref(i_wl));
Key point: Hyper-a does not convert counts to absorption using a single multiplicative calibration coefficient. The measured ratio is interpreted through the calibrated integrating-cavity forward model, and \(a(\lambda)\) is obtained by nonlinear inversion.

10. Complete Processing Chain

\[ \boxed{ \text{Factory calibration} \rightarrow \left(r,r_0,\rho_{\mathrm{factory}},a_{\mathrm{spot}}\right) } \]
\[ \boxed{ \text{Pure water + White plug} \;\&\; \text{Pure water + ND black spot} \rightarrow \rho_{\mathrm{field}}(\lambda) } \]
\[ \boxed{ H_{\mathrm{sample}}/H_{\mathrm{water}} \rightarrow T_{\mathrm{obs}}(\lambda) } \]
\[ \boxed{ T_{\mathrm{obs}} = F\!\left[ a(\lambda); r,r_0,\rho_{\mathrm{field}}(\lambda),a_W(\lambda) \right] } \]
\[ \boxed{ \text{Nonlinear inversion} \rightarrow a_{\mathrm{sample}}(\lambda) } \]
Known absorption standard → sphere reflectivity → cavity optical model → sample absorption

1. 개요

Hyper-a는 integrating cavity를 이용하여 시료의 분광 흡광계수 \(a(\lambda)\)를 측정한다. 이 과정은 단순한 gain/offset 교정이나 직접적인 Beer–Lambert 계산이 아니다. 적분구 내부에서 발생하는 다중 반사와 유효 광경로를 명시적으로 고려하는 PSICAM 계열의 적분구 광학 모델을 사용한다.

2. 원시 분광자료의 기본 보정

Signal detector와 reference detector의 원시 count에서 시간적으로 가장 가까운 dark 측정값을 제거한다.

\[ S'(\lambda)=S_{\mathrm{raw}}(\lambda)-S_{\mathrm{dark}}(\lambda) \] \[ R'(\lambda)=R_{\mathrm{raw}}(\lambda)-R_{\mathrm{dark}}(\lambda) \]

이후 signal과 reference spectrum을 cal.wl로 정의된 공통 파장축에 보간한다. 최종적으로 기본 Hyper-a 신호는 다음과 같이 계산된다.

\[ \boxed{ H(\lambda)=\frac{S'(\lambda)}{R'(\lambda)} } \]
MATLAB 구현 — Hypera_lib.m, 함수 CorrectSpectrum()
sig_darkCorr = lightData.sigPix(n,:) ...
             - medianDarkData.median_sigPix(closestIndex,:);

ref_darkCorr = lightData.refPix(n,:) ...
             - medianDarkData.median_refPix(closestIndex,:);

AllDarkRefCorrected(n,:) = ...
    interp1(config.sigWls(:)', sig_darkCorr, cal.wl(:)') ./ ...
    interp1(config.refWls(:)', ref_darkCorr, cal.wl(:)');

따라서 CorrectSpectrum()의 역할은 dark subtraction → wavelength interpolation → signal/reference normalization 으로 정리할 수 있다.

3. 적분구 광학 모델

적분구 모델의 핵심 확률함수 \(P_s\)는 Hypera_lib.Ps()에 구현되어 있다.

\[ \boxed{ P_s(a,r)= \frac{1-e^{-2ar}(2ar+1)} {2a^2r^2} } \]
MATLAB 구현 — Hypera_lib.m, 함수 Ps()
Ps_x = (1 - exp(-2 .* a .* r) .* (2 .* a .* r + 1)) ...
     ./ (2 .* a.^2 .* r.^2);

서로 다른 두 흡광 상태 A와 B의 보정된 Hyper-a 신호를 \(H_A\), \(H_B\)라 하면

\[ T_{AB}(\lambda)=\frac{H_A(\lambda)}{H_B(\lambda)} \]

이 비율은 \(a_A\), \(a_B\), \(r\), \(r_0\), 그리고 적분구 반사율 \(\rho(\lambda)\)의 함수로 표현된다.

4. Factory Calibration: 적분구 반사율 결정

Factory calibration의 목적은 적분구의 유효 분광 반사율 \(\rho(\lambda)\)를 결정하는 것이다.

흡광계수를 알고 있는 두 상태의 \(a_A(\lambda)\), \(a_B(\lambda)\)와 실제 측정된 \(T_{AB}=H_A/H_B\)를 사용하여 \(\rho\)를 역산한다.

\[ \boxed{ \rho(\lambda)= \frac{ T_{AB}e^{-a_Br_0}P_s(a_B,r) - e^{-a_Ar_0}P_s(a_A,r) }{ T_{AB}e^{-a_Br_0}P_s(a_A,r)P_s(a_B,r) - e^{-a_Ar_0}P_s(a_B,r)P_s(a_A,r) } } \]
알려진 \(a_A,a_B\) + 측정된 \(H_A,H_B\) → \(T_{AB}\) → \(\rho(\lambda)\)
MATLAB 구현 — Hypera_lib.m, 함수 ComputeRho()
T_AB = A_hypera ./ B_hypera;
T_AB = smoothdata(T_AB, 2, 'sgolay', 15);

rho = (T_AB .* exp(-a_B .* r_0) .* Hypera_lib.Ps(a_B,r) ...
     - exp(-a_A .* r_0) .* Hypera_lib.Ps(a_A,r)) ...
    ./ ...
     (T_AB .* exp(-a_B .* r_0) .* Hypera_lib.Ps(a_A,r) .* Hypera_lib.Ps(a_B,r) ...
     - exp(-a_A .* r_0) .* Hypera_lib.Ps(a_B,r) .* Hypera_lib.Ps(a_A,r));

5. ND Spot Field Calibration

현장에서는 적분구 내부에 pure water를 넣은 상태에서 Fluorilon white plug와 ND black spot을 각각 측정하여 현재 장비의 optical state에 해당하는 새로운 \(\rho(\lambda)\)를 계산한다.

5.1 White plug 측정

Pure water와 Fluorilon white plug가 설치된 상태에서는 흡광 상태를 pure-water absorption으로 나타낸다.

\[ \boxed{ a_W(\lambda)=a_{\mathrm{water}}(\lambda,T_W,S=0) } \]
MATLAB 구현 — Hypera_RhoFromNDSpot.m
purewater_DarkRefCorrected = ...
    Hypera_lib.CorrectSpectrum(cal, pureWater.dataTable, pureWater.config);

PureWater_aW_modeled = ...
    Hypera_lib.Get_IOCCG_aW(cal.wl, T_pureWater, 0)';

5.2 ND black spot 측정

Pure water를 유지한 상태에서 white plug를 ND black spot으로 교체한다. ND spot 자체의 알려진 equivalent absorption spectrum은 cal.spotAbsorp에 저장되어 있다.

\[ \boxed{ a_B(\lambda)= a_{\mathrm{water}}(\lambda,T_B)+a_{\mathrm{spot}}(\lambda) } \]
MATLAB 구현 — Hypera_RhoFromNDSpot.m
spot_DarkRefCorrected = ...
    Hypera_lib.CorrectSpectrum(cal, spot.dataTable, spot.config);

Cal_spot_aW_modeled = ...
    Hypera_lib.Get_IOCCG_aW(cal.wl, T_spot, 0)';

Cal_spot_a_total = cal.spotAbsorp + Cal_spot_aW_modeled;

6. White/Black 측정으로부터 현장 ρ 계산

White plug 상태의 보정된 신호를 \(H_W(\lambda)\), ND black spot 상태의 보정된 신호를 \(H_B(\lambda)\)라고 하면

\[ \boxed{ T_{BW}(\lambda)=\frac{H_B(\lambda)}{H_W(\lambda)} } \]

Hypera_lib.ComputeRho()를 호출할 때 ND spot 상태가 A, white-plug pure-water 상태가 B로 입력된다.

\[ a_A=a_{\mathrm{water}}+a_{\mathrm{spot}}, \qquad a_B=a_{\mathrm{water}} \]
\[ \boxed{ \left[ a_{\mathrm{water}}, a_{\mathrm{spot}}, \frac{H_B}{H_W}, r, r_0 \right] \longrightarrow \rho_{\mathrm{field}}(\lambda) } \]
MATLAB 구현 — Hypera_RhoFromNDSpot.m
rho = Hypera_lib.ComputeRho( ...
    cal.r, ...
    cal.r_0, ...
    Cal_spot_a_total, ...
    PureWater_aW_modeled, ...
    median(spot_DarkRefCorrected.NoFilter, 1), ...
    median(purewater_DarkRefCorrected.NoFilter, 1));

rho = smoothdata(rho, "sgolay", 30);
해석: White/Black 절차는 단순한 drift diagnostic index를 만드는 과정이 아니다. 이 절차를 통해 파장별 새로운 sphere reflectivity \(\rho_{\mathrm{field}}(\lambda)\)가 직접 산출된다.

7. Factory와 Field Calibration의 관계

\[ \boxed{ \text{Factory calibration} \longrightarrow r,\;r_0,\;\rho_{\mathrm{factory}}(\lambda),\; a_{\mathrm{spot}}(\lambda) } \]

Factory calibration에서 특성이 결정된 ND spot은 이후 현장에서 transfer standard 역할을 한다.

\[ \boxed{ a_{\mathrm{spot}}(\lambda) + \text{White/Black measurements} \longrightarrow \rho_{\mathrm{field}}(\lambda) } \]

따라서 cal.spotAbsorp는 사전에 특성이 결정된 ND spot의 calibration characteristic이고, \(\rho(\lambda)\)는 실제 측정 시점의 cavity response를 나타내는 중간 교정 변수이다.

코드상 주의점: Hypera_RhoFromNDSpot()는 새로운 rho를 반환하지만 함수 내부에서 cal.rho를 직접 덮어쓰지는 않는다. 따라서 이후 sample retrieval에 새 reflectivity를 사용하려면 호출부에서 cal.rho에 새 값을 대입하거나 갱신된 calibration structure를 구성해야 한다.

8. 실제 시료의 흡광계수 산출

교정 이후 pure water를 optical reference로 사용하고 unknown sample을 측정한다. 두 자료 모두 dark/reference correction을 수행한 뒤 sample-to-water ratio를 계산한다.

\[ \boxed{ T_{\mathrm{obs}}(\lambda)= \frac{ H_{\mathrm{sample}}(\lambda) }{ \operatorname{median}[H_{\mathrm{water}}(\lambda)] } } \]
MATLAB 구현 — Hypera_lib.m, 함수 ComputeAbsorption()

r_0 = cal.r_0;
rho = cal.rho;

T_AB = hypera_sample ./ median(hypera_pureWater, 1);

9. Forward Model과 비선형 역산

미지 시료의 흡광계수를 \(a(\lambda)\), reference pure-water absorption을 \(a_W(\lambda)\)라고 하면, 주어진 \(a\)에 대해 모델이 예측하는 Hyper-a signal ratio는 다음과 같다.

\[ \boxed{ \hat{T}(a,\lambda)= e^{-r_0[a(\lambda)-a_W(\lambda)]} \, \frac{ 1-\rho(\lambda)P_s(a_W,r) }{ 1-\rho(\lambda)P_s(a,r) } \, \frac{ P_s(a,r) }{ P_s(a_W,r) } } \]
MATLAB forward model — Hypera_lib.m, 함수 ComputeAbsorption()
T_AB_guess = @(a_guess) ...
    exp(-r_0 .* (a_guess - aW_ref(i_wl))) ...
    .* ((1 - rho(i_wl) .* Hypera_lib.Ps(aW_ref(i_wl),r)) ...
    ./  (1 - rho(i_wl) .* Hypera_lib.Ps(a_guess,r)) ...
    .*  Hypera_lib.Ps(a_guess,r) ...
    ./  Hypera_lib.Ps(aW_ref(i_wl),r));

실제 관측값과 모델 예측값의 상대오차가 최소가 되는 \(a\)를 찾는다.

\[ E(a)= \frac{ \left|\hat T(a,\lambda)-T_{\mathrm{obs}}(\lambda)\right| }{ T_{\mathrm{obs}}(\lambda) } \]
\[ \boxed{ a_{\mathrm{Hyper\!-\!a}}(\lambda) = \underset{a}{\operatorname{argmin}} \; \frac{ \left|\hat T(a,\lambda)-T_{\mathrm{obs}}(\lambda)\right| }{ T_{\mathrm{obs}}(\lambda) } } \]
MATLAB 역산 — Hypera_lib.m, 함수 ComputeAbsorption()
ToMinimize = @(a_guess) ...
    abs(T_AB_guess(a_guess) - T_AB(i_meas,i_wl)) ...
    ./ T_AB(i_meas,i_wl);

a_tot_hypera(i_meas,i_wl) = ...
    fminsearch(ToMinimize, aW_ref(i_wl));
핵심: Hyper-a는 하나의 multiplicative calibration coefficient를 count에 곱해 absorption으로 변환하는 장비가 아니다. 측정된 signal ratio를 calibrated integrating-cavity forward model로 해석하고, 비선형 역산을 통해 \(a(\lambda)\)를 결정한다.

10. 전체 처리 흐름

\[ \boxed{ \text{Factory calibration} \rightarrow \left(r,r_0,\rho_{\mathrm{factory}},a_{\mathrm{spot}}\right) } \]
\[ \boxed{ \text{Pure water + White plug} \;\&\; \text{Pure water + ND black spot} \rightarrow \rho_{\mathrm{field}}(\lambda) } \]
\[ \boxed{ H_{\mathrm{sample}}/H_{\mathrm{water}} \rightarrow T_{\mathrm{obs}}(\lambda) } \]
\[ \boxed{ T_{\mathrm{obs}} = F\!\left[ a(\lambda); r,r_0,\rho_{\mathrm{field}}(\lambda),a_W(\lambda) \right] } \]
\[ \boxed{ \text{Nonlinear inversion} \rightarrow a_{\mathrm{sample}}(\lambda) } \]
Known absorption standard → sphere reflectivity → cavity optical model → sample absorption
